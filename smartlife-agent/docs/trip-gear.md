# 行程约束派生与装备协同规划

## 一句话

给定一句出行需求，系统派生出一份**可追溯的约束清单**，生成**逐日行程**，由行程推导**装备清单**，再从对话/记忆判断**已有装备**、用现有商品库补**缺口**，最后按预算、时间、装备齐全性做**确定性校验**，预算不够时在有限轮次内**自动削减可选装备**。

## 链路

```text
用户一句话
   │
   ├─ 约束派生      constraints.py
   │    用户明说：目的地/天数/人数/预算/住宿/交通/儿童
   │    规则推出：周末→2 天、预算默认含装备、夜温→睡袋温标
   │    外部事实：天气（失败时明确降级，不猜温度）
   │
   ├─ 逐日行程      itinerary.py
   │    每天：时间 / 活动 / 时长 / 花费
   │
   ├─ 装备推导      gear.py
   │    只看整趟事实 + 活动文字，不给条目打标签
   │
   ├─ 已有判定      owned.py
   │    本轮对话、上文用户发言、长期记忆；只认“我有/买了/带了”
   │
   ├─ 缺口匹配      shopping.py
   │    复用 ProductRepository，按装备名检索并挑预算内商品
   │
   └─ 校验修复      verify.py + graph.py
        预算（含装备）/ 时间重叠 / 天数 / 露营三件套
        超预算 → 有限轮次内砍可选装备 → 仍超则如实报告
```

图定义在 `graph.py`，节点依次是
`derive → plan → gear → owned → shop → verify →(repair → verify)→ finalize`。

## 三个结构，字段是固定的

```text
约束  4 个字段：内容、来源、硬度、状态
行程  4 个字段：时间、活动、时长、花费
装备  4 个字段：名称、数量、理由、状态
```

**场景不是枚举出来的**：不维护“商务/度假/户外”场景表。行程条目就是自然语言活动，模型填属性、规则按属性出清单。新增场景不需要新增字段。

**装备不限于户外**：这次出行要带的东西都算——衣物、正装、鞋、洗护、药品、儿童用品、户外装备。裙子、西装、皮鞋和帐篷、睡袋走的是同一条链路。

## 预算口径

- 默认 **含装备**：用户说“预算 1500”，行程和装备合计不得超过 1500。
- 用户明说“不含装备/装备另算” → 只校验行程，装备单独列。
- 用户说“装备预算 500” → 记录单独的装备预算并单独校验。

## 装备状态

| 状态 | 含义 | 来源 |
|---|---|---|
| `owned` | 已有 | 本轮对话、上文用户发言、长期记忆 |
| `need_buy` | 需要购买 | 规则推导；有商品则带价格 |
| `self_provided` | 自备、平台不卖 | 通用底座（证件/手机/药品等） |
| `skipped` | 按预算省略 | 修复阶段砍掉的可选装备 |

“已有”只认明确表述：`我有帐篷`、`上周买了睡袋`、`带了登山杖` 算；
`我想买帐篷`、`需要买睡袋`、`推荐露营装备` 不算。
记忆里的“用户买了帐篷”算，并保留 `记忆:<id>` 出处。

## 派生规则

| 条件 | 装备 |
|---|---|
| 住宿=露营 | 帐篷、睡袋、防潮垫、头灯 |
| 夜间 ≤15℃ | 保暖层；露营时睡袋温标 ≤ 夜温−5℃ |
| 降水概率 ≥40% | 雨具、防水鞋 |
| 高温或水上活动 | 防晒霜、帽子、墨镜 |
| 水上活动 | 泳衣、速干衣、防水袋 |
| 活动含正式场合 | 正装、皮鞋 |
| 天数 ≥3 | 换洗衣物（天数−1）、洗衣袋 |
| 同行有儿童 | 儿童衣物、儿童常用药、湿巾 |
| 坐飞机 | 液体分装瓶 |
| 徒步/登山 | 登山鞋、双肩包 |
| 每次都有 | 证件、手机、充电器、充电宝、常用药、洗漱、纸巾、钱包、钥匙、口罩、眼镜、水杯、护肤品、垃圾袋 |

规则只看整趟事实和活动文字，不读行程条目标签。

## 路由

- `is_gear_request()` 判断“出行语境 + 装备/清单/带什么”，或“露营/徒步等强场景且不是在问买什么”。
- `OrchestratorV2.classify_turn` 里有安全网：命中后置为 `travel + gear_plan`，避免被“帐篷/睡袋”等商品词带到购物子图。
- `LangGraphOrchestrator` 新增 `trip_gear` 节点，走 `run_trip_gear_turn`。
- 普通旅行（“去杭州玩两天”）仍走原 `travel` 节点。
