省钱旅行攻略 - 高性价比出行指南

【交通省钱】
1. 提前订机票/火车票，避开节假日高峰
2. 使用比价平台对比价格
3. 市内优先选择公共交通
4. 短途可以考虑顺风车/拼车

【住宿省钱】
1. 民宿比酒店性价比高
2. 青年旅社适合独行背包客
3. 提前预订享受早鸟价
4. 避开核心景区住宿，交通方便即可

【餐饮省钱】
1. 选择当地人的餐馆而非游客餐厅
2. 午餐吃正餐，晚餐小吃为主
3. 自带水杯，景区饮料贵
4. 可以去当地菜市场体验和采购

【景点省钱】
1. 很多自然景观免费（西湖、公园）
2. 学生证/军人证享受优惠
3. 关注景区联票和年卡
4. 淡季出行门票可能有折扣

【推荐预算路线】
- 杭州3天2晚：2000元/人（含交通住宿餐饮）
- 成都4天3晚：2500元/人
- 云南5天4晚：3000元/人
