# 记忆系统改造总结

## 改造目标

1. **去掉自动压缩**：不再每20条消息自动压缩
2. **去掉自动保存事件**：不再每轮对话自动保存事件
3. **用户手动触发保存**：用户决定是否保存记忆
4. **对话结束后提取候选记忆**：小模型提取有价值信息，用户决定是否保留
5. **向量库 + MD 文档并存**：两种存储方式各有优势
6. **修复 NL2SQL 问题**：改进提示词，增加模糊匹配和重试机制

## 改动文件

### 1. 新增文件

#### `app/memory/md_memory.py`
- MD 文档记忆管理器
- 支持偏好和事件两种类型
- 支持增删改查操作
- 自动生成索引文件

#### `app/memory/extractor.py`
- 记忆提取器
- 从对话中提取候选记忆
- 只提取事实，不推断偏好
- 支持格式化显示和用户选择解析

### 2. 修改文件

#### `app/memory/__init__.py`
- 新增导出 `MDMemory`

#### `app/agents/orchestrator_v2.py`
- **去掉** `_save_memories` 中的自动压缩逻辑（`len(history) % 20 == 0`）
- **去掉** 自动保存事件逻辑
- **新增** `extract_candidate_memories()` 方法：提取候选记忆
- **新增** `get_candidate_display()` 方法：格式化候选记忆显示
- **新增** `save_user_selected_memories()` 方法：保存用户选择的记忆
- **新增** `compress_conversation()` 方法：手动压缩对话
- **新增** `save_compressed_summary()` 方法：保存压缩后的摘要
- **保留** 原有的流式处理逻辑（`_run_shopping_streaming`, `_run_general_streaming`, `_smart_retrieve` 等）

#### `app/main.py`
- **恢复** 原有的侧边栏配置（主模型、小模型、Embedding）
- **新增** 候选记忆提取 UI：对话结束后显示候选记忆，用户选择保存
- **新增** 手动压缩 UI：用户可手动压缩对话
- **新增** MD 文档记忆管理 UI：显示、编辑、删除 MD 文档记忆
- **修改** 个人中心：同时显示向量库和 MD 文档记忆条数

#### `app/retrieval/nl2sql.py`
- **改进** 提示词：增加详细示例和商品分类体系
- **新增** 术语映射：用户语言到数据库术语的映射
- **新增** 模糊匹配：当 LLM 查询无结果时，使用模糊匹配
- **新增** 重试机制：最多重试 2 次

## 新增流程

### 记忆提取流程

```
对话结束
    ↓
小模型提取候选记忆（只提取事实，不推断偏好）
    ↓
规则过滤（去重、去噪、去无意义内容）
    ↓
展示给用户：
  "检测到以下信息，是否保存？"
  - 买了一双 37 码鞋（✅ 保留 / ❌ 不保留）
  - 预算 500 元（✅ 保留 / ❌ 不保留）
    ↓
用户选择后写入 MD + 向量库
```

### 手动压缩流程

```
用户点击"压缩当前对话"
    ↓
小模型压缩对话为摘要
    ↓
显示压缩结果
    ↓
用户确认后保存
```

## 双轨并存设计

```
memory_docs/
└── user_001/
    ├── preferences.md    ← 用户偏好（手动维护）
    ├── events.md         ← 事件记录
    └── index.json        ← ID 映射表

memory_db/
└── chroma.sqlite3        ← 向量索引
```

- MD 是权威源，向量库是索引
- 用户编辑 MD → 删除时同步删除向量条目

## NL2SQL 改进

### 问题
1. 提示词不够详细，没有示例
2. 没有处理模糊查询
3. 没有 fallback 机制

### 解决方案
1. **详细提示词**：增加商品分类体系和示例
2. **术语映射**：用户语言到数据库术语的映射（如"鞋子" → ["跑步鞋", "登山鞋", "运动鞋"]）
3. **模糊匹配**：当 LLM 查询无结果时，使用模糊匹配
4. **重试机制**：最多重试 2 次

## 使用说明

### 1. 记忆提取
- 每次对话结束后，系统会自动提取候选记忆
- 用户可以选择保存或跳过
- 只保存用户明确选择的记忆

### 2. 手动压缩
- 在个人中心点击"压缩当前对话"
- 查看压缩结果
- 确认后保存

### 3. MD 文档记忆管理
- 在个人中心查看所有 MD 文档记忆
- 支持编辑和删除操作
- 删除后自动同步到向量库

### 4. NL2SQL 查询
- 支持模糊匹配（如"鞋子"会匹配所有鞋类产品）
- 空结果时自动重试
- 提供详细的查询解释

## 注意事项

1. **记忆不自动保存**：用户必须手动选择保存
2. **只提取事实**：小模型不推断偏好，只提取明确提到的事实
3. **双轨并存**：MD 文档是权威源，向量库是索引
4. **向量库同步**：MD 文档的修改会同步到向量库
